# mybox

Личное зашифрованное хранилище поверх Google Drive. Одна веб-страница без сервера.

- Снаружи — обычная страница (монохромные часы). Набор секретного слова открывает вход.
- Вход — 12 слов, как сид-фраза криптокошелька. Больше ничего: ни пароля, ни повторного входа в Google.
- Файлы шифруются в браузере. В Google уходят нечитаемые байты с нечитаемыми именами.
- Доступ к Google «вечный»: страница сама обновляет его, окно входа появляется только один раз при настройке.

Готовые файлы — в `dist/`: `index.html` и `sw.js`.

## Настройка (один раз)

1. Залей `index.html` и `sw.js` в репозиторий с GitHub Pages (или любой сайт с https).
2. В Google Cloud → Google Auth Platform → **Clients** → у своего клиента (тип Web application) добавь:
   - **Authorized JavaScript origins**: `https://<логин>.github.io`
   - **Authorized redirect URIs**: `https://<логин>.github.io/<репозиторий>/`
3. Там же → **Audience** → **Publish app** (иначе Google рвёт доступ каждые 7 дней).
4. Открой страницу, набери секретное слово, пройди 3 шага: фраза из 12 слов → Client ID + Client secret → вход в Google.
5. Скачается `vault.dat`. Залей его в тот же репозиторий, рядом с `index.html`.

После этого с любого устройства: секретное слово → 12 слов → хранилище.

## Секретное слово («двойное дно»)

По умолчанию — `миронов`. Набирается где угодно на странице (не в поле), ловится при любой раскладке; на телефоне — в поле «команда» на обложке. Хранится хэшем в коде, не текстом. Чтобы сменить — поменяй `SECRET_DEFAULT` в `src/app.js` (хэш SHA-256 слова в нижнем регистре и его длину) и пересобери.

## Что умеет

- Папки, перетаскивание файлов внутрь, переименование, выделение и удаление, загрузка папок целиком.
- Просмотр фото и PDF, видео с перемоткой без полного скачивания, плеер аудио (нижняя панель, очередь).
- Редактор txt/md с просмотром разметки, создание файлов.
- Поиск, список/плитка с миниатюрами, адаптив под телефон.

## Безопасность

- Ключ файлов и ключ `vault.dat` выводятся из 12 слов (scrypt). 12 слов BIP39 = 128 бит, перебор невозможен.
- `vault.dat` зашифрован фразой, поэтому его не страшно держать в публичном репозитории. Внутри — Client ID, Client secret и вечный токен Google.
- Политика безопасности (CSP) в `index.html`: выполняется только этот код (сверяется отпечаток), сеть — только к Google.
- Кто узнает 12 слов — получит доступ. Фразу нельзя восстановить. Запиши её на бумаге.

## Формат = rclone crypt

Содержимое файлов — формат rclone (стандартные настройки crypt), пароль = 12 слов через пробел.
Аварийно открыть всё без страницы:

```
rclone copy ":crypt,remote=/путь/к/vault,password=$(rclone obscure 'двенадцать слов через пробел'):" ./расшифровано
```

## Ограничения

- Загрузка прерывается при закрытии вкладки.
- HEIC-фото браузеры не показывают — скачиваются.
- Если доступ к Google отозван (6 мес. простоя, смена пароля, отзыв вручную) — «Настроить заново».

node test/e2e.mjs              # прогон страницы в браузере (нужны SCRATCH, RCLONE)
